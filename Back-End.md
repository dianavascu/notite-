Front-End-ul reprezintă interfața vizuală cu care interacționează utilizatorul (HTML, CSS, JavaScript), în timp ce Back-End-ul reprezintă logica din spate, gestionată de un framework precum Django (scris în Python).
-Browserul trimite o cerere (_HTTP Request_) către server (de exemplu: „Verifică parola utilizatorului X”).
-Codul Back-End procesează cererea, interoghează baza de date și generează răspunsul.
-Serverul trimite înapoi răspunsul (_HTTP Response_) către Front-End pentru a fi afișat.

**Limbaje/Framework-uri Back-End populare:** Python (Django, Flask), JavaScript (Node.js), PHP (Laravel), Java (Spring), C# (.NET).
